# Definitions of the eight outputs and the outcome taxonomy

## Outcomes

| Code | Name | In p(DOOM)? |
| --- | --- | --- |
| O0 | Beneficial or manageable transition | no |
| O1 | Serious but reversible harm | no |
| O2 | Systemic authoritarian or oligopolistic control (resistance remains possible) | no |
| O3 | Permanent severe human disempowerment | yes (P-DISEMPOWERMENT) |
| O4 | Civilizational collapse | yes (P-COLLAPSE with O5) |
| O5 | Near-extinction | yes (P-COLLAPSE with O4) |
| O6 | Human extinction | yes (P-EXTINCTION) |
| O7 | Biospheric catastrophe | yes (P-BIOSPHERE) |
| O8 | Other irreversible loss | yes |

p(DOOM) is shown only next to this decomposition. Extinction and disempowerment are never combined silently.

## Horizons

1y, 3y, 5y, 10y, 25y from the forecast origin date; "2100" is a calendar endpoint; "eventual" has no endpoint and is never displayed beside a dated horizon without a prominent label. No countdown is ever shown.

## The eight outputs

A. External forecast aggregate — probability, aggregated from named sources inside compatibility groups.
B. p(DOOM) model estimate — probability from the research-mode model; the official object is `insufficiently_calibrated`.
C. Evidence Pressure Index — 0–100 movement relative to the baseline release.
D. Capability Pressure Index — 0–100.
E. Control Strength Index — 0–100.
F. Incident Pressure Index — 0–100.
G. Uncertainty Score — 0–100.
H. Editorial risk level — very_low, low, guarded, elevated, high, severe_uncertainty, insufficient_evidence.

C–H are not probabilities and are never converted into one.
